# Installer ou mettre à jour M.I.A.O.

Le guide canonique se trouve dans [docs/INSTALLATION.md](docs/INSTALLATION.md).

Pour mettre à jour ton installation actuelle :

1. ferme le script PowerShell M.I.A.O. ;
2. conserve `miao-mission.txt`, `miao-settings.json` et ton fichier `.bat` ;
3. extrais tout le nouveau dossier par-dessus l’ancien ;
4. relance le même fichier `.bat` ;
5. conserve les URLs OBS `http://127.0.0.1:8974/` et `http://127.0.0.1:8974/control`.

L’archive ne contient pas tes deux fichiers de données : elle ne peut donc pas remplacer ta transmission ni tes réglages.
